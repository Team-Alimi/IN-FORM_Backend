## api 제작 여부 ##

## 기본 목록 보기 & 상세 보기 ##
### /api/v1/school_articles ###
- [X] 학교 게시글 목록 보기
### /api/v1/school_articles/{article_id} ###
- [X] 학교 게시글 상세 정보 확인하기
### /api/v1/club_articles ###
- [X] 동아리 게시글 목록 보기
### /api/v1/club_articles/{article_id} ###
- [X] 동아리 게시글 상세 정보 확인하기

## 캘린더 관련 ##
### /api/v1/monthly ###
- [X]  달에 포함된 전체 글(학교글 + 동아리 글) 목록 보기
### /api/v1/monthly/school_articles ###
- [X] 특정 달에 포함된 학교 글 목록 보기
### /api/v1/monthly/club_articles ###
- [X] 특정 달에 포함된 동아리 글 목록 보기

## 마감 기한 임박 보기 ##

### api/v1/deadline/school_articles ###
- [X] 마감기한 임박한 학교 게시글 목록 보기 (끝나기 5일전)

### api/v1/deadline/club_articles ###
- [X] 마감기한 임박한 동아리 게시글 목록 보기 (끝나기 5일전)
