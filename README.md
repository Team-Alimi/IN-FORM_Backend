spring 부트로 api 제작 시 대략 이런식으로 제작하면 됩니다.

## 프로젝트 진행 시 주의사항 ##
기본적으로 application.properties 파일 안에 데이터베이스 비번,포트번호 등 민감 정보들이 적히게됩니다.
그래서 .gitignore에서 해당 파일을 add하지 않도록 설정해주는 것이 중요합니다.

.gitignore로 해당 파일을 업로드하지 않게 되면, clone 후에 application.properties 파일의 설정을 해주어야합니다.
해당 설정은 다음의 블로그를 참고해주세요.
https://intshc.tistory.com/57

## test 코드에 관해서 ##
test 패키지 안에 적힌 코드들은 말 그대로 해당 기능들을 테스트하기 위한 코드이므로 실제 MyApplication 실행 시에 프로그램에 영향을 끼치진 않습니다.

프로그램 규모가 커지는 경우, 수많은 코드를 한번에 작성했다가 버그가 생기면 수정하기가 어려울 수 있으므로 단위테스트를 진행하는 습관을 드리는 것도 좋을 것 같습니다.
